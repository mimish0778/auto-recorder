# 10s Take Recorder

研究用の動画収録ツールです。3・2・1 のカウントダウンのあと、ちょうど 10 秒間の動画を撮って自動で保存します。

被験者ごとに撮り方がぶれないよう、**解像度・尺・フレーム数・顔の位置** をできるだけ揃えて収録することを目的にしています。ブラウザだけで動き、`index.html` 1 ファイルで完結しています（外部ライブラリなし）。

| 項目 | 仕様 |
|---|---|
| 尺 | 10 秒（30fps × 300 フレーム） |
| 解像度 | 540×960（縦長 9:16）固定 |
| 音声 | なし（マイクにもアクセスしません） |
| 形式 | MP4（ブラウザが非対応なら WebM） |
| ファイル名 | `{position}_{番号3桁}.mp4`（例: `pos2_004.mp4`） |

## 動かし方

カメラは HTTPS か localhost でしか使えないので、GitHub Pages などに置いて URL から開くか、ローカルサーバー経由で開いてください。

```sh
python -m http.server
# → http://localhost:8000 を開く
```

`index.html` をダブルクリックして `file://` で開くと、ブラウザによってはカメラが起動しません。

**収録には PC（Chrome / Edge のデスクトップ版）を使ってください。** スマートフォンでは仕様どおりに撮れないことを確認しています（[PC とスマートフォンの違い](#pc-とスマートフォンの違い)）。

## 使い方

1. **Position** で `pos0`〜`pos4` のどれかを選ぶ（ファイル名のラベルになります）
2. **Start #** にファイル番号を入れる（例: `4` → `pos2_004.mp4`）
3. 楕円の顔ガイドに顔が収まるように被験者の位置を合わせる
4. **START** を押す
5. 3・2・1 のあと 10 秒間録画され、自動で停止・ダウンロードされます

録画中とカウントダウン中は、Position・Start #・カメラ切り替えがロックされます。

### 番号は自動で増えません

わざとそうしています。同じ番号のまま何度でも撮り直せますし、Position だけ変えて `pos0_001` → `pos1_001` のように撮ることもできます。別の番号にしたいときは Start # を書き換えてください。

撮り直しても前のファイルは上書きされず、ブラウザが `pos2_001 (1).mp4` のような別名で保存します。どれを採用するか決めて、不要なファイルは消しておいてください。同じセッション内で保存済みの番号をもう一度使うと、ログに `DUPLICATE name` と出ます。

### STOP ボタン

STOP は中断専用です。押したテイクは保存されません。

- カウントダウン中 → 録画は始まらずキャンセル
- 録画中 → そのテイクは破棄（`✖ Discarded`）

また、録画中にタブがバックグラウンドに回った場合も、タイミングが崩れるのでそのテイクは破棄されます。**保存されるのは 10 秒を撮り切ったテイクだけ** です。

### 保存後のチェック

保存時に尺とフレーム間隔を自動でチェックし、結果をログに出します。

- `✔ Saved ...` — 問題なし
- `⚠ Saved ... FLAGGED: ...` — 保存はされたが要確認

FLAGGED になる主な理由は、実尺が 10 秒 ±0.3 秒を外れた、フレーム間隔が乱れた、カメラの解像度が足りず引き伸ばした、時間ベースで収録した、番号が重複した、のいずれかです。データとして使う前にログを確認してください。

## 画面の見方

| 表示 | 意味 |
|---|---|
| 上部の「FRONT / BACK camera」 | 使用中のカメラ |
| 右上のカメラアイコン | 前面／背面の切り替え |
| 黄色「Source resolution below target」 | カメラの解像度が 540×960 に届かず、引き伸ばして保存している |
| 黄色「Frame-lock unsupported — TIME-BASED」 | フレーム単位の制御ができない環境。フレーム数がぶれる |
| 赤い「Recording」とタイマー | 録画中（`123/300` のようにフレーム数、時間ベースでは `00:07` のように秒数） |
| 下部のログ | 準備完了・録画中・保存・破棄・警告などの状態 |

### プレビューと顔ガイド

- プレビューに見えている範囲がそのまま保存されます。カメラ映像は左右を中央基準でトリミングして 540×960 に収めています。
- 顔ガイド（破線の楕円）は表示だけで、動画には写りません。
- 前面カメラのときプレビューは鏡像で表示されますが、**保存される動画は鏡像ではありません**（カメラが捉えたままの向き）。

## フレーム数について

対応ブラウザでは `requestFrame()` を使って 1 フレームずつ書き出す「フレーム完全一致モード」で動きます。非対応の場合は「時間ベースモード」に切り替わり、黄色い TIME-BASED の警告が出ます。時間ベースではフレーム数が大きくぶれるので、研究データの収録には使わないでください。

フレーム完全一致モードでも、エンコード後のフレーム数はちょうど 300 にはならず、実測で **298〜301** 程度ぶれます（尺は 9.95〜10.01 秒程度）。ブラウザが `requestFrame()` 1 回につき必ず 1 フレーム出すことを保証していないためで、アプリ側では制御できません。

解析するときは次の点に気をつけてください。

- 「先頭 300 フレームを使う」前処理は使えません（298 フレームのファイルがあるため）
- テイク間で揃えるなら、等間隔に N フレーム抜き出す（例: どのファイルからも 290 フレーム）か、時間で正規化する
- ±数フレームは 10 秒に対して約 0.7%、数十ミリ秒の差で、咀嚼のような連続運動の解析なら通常は問題になりません
- 極端に外れたテイク（290 未満、310 超など）は除外するか撮り直す

## PC とスマートフォンの違い

| 項目 | PC（実測） | スマートフォン（実測） |
|---|---|---|
| 解像度 | 540×960（仕様どおり） | 360×640 |
| フレーム数 | 298〜301 | 233（実質 23fps 台） |
| 尺 | 約 10.00 秒 | 9.97 秒 |

スマートフォンではフレーム完全一致モードが使えず、処理能力や再エンコードの影響でフレームが大量に落ちます。**PC とスマートフォンで撮ったデータは同じデータセットに混ぜないでください。** 収録環境は 1 つに固定し、カメラ・照明・被験者との距離も全テイクで揃えるのがおすすめです。

## 研究で使うときの注意

- **データ収集を始めたら設定を変えないでください。** 解像度やフレーミングを変えると顔の写り方の基準が変わり、前のデータと比較できなくなります。
- 動画は鏡像なしで保存されるので、前面カメラでは被験者の右側がフレームの左側に写ります。左右のラベルをどちらの基準で付けるか統一し、機械学習に使う場合は左右反転のデータ拡張をオフにしてください。
- 収録した動画はどこにもアップロードされず、すべてブラウザ内で処理されてダウンロードフォルダに保存されます。**被験者の動画を公開リポジトリにコミットしないでください。**

### ffprobe での確認

撮り終わったら、各ファイルの「540×960・フレーム数 300 前後・音声なし」を確認しておくと安心です。

サイズ・フレーム数・尺（`width=540` `height=960` `duration≈10.0`、`nb_read_frames` が 300 前後なら OK）:

```sh
ffprobe -v error -count_frames -select_streams v:0 \
  -show_entries stream=width,height,nb_read_frames \
  -show_entries format=duration \
  -of default=noprint_wrappers=1 pos2_001.mp4
```

音声トラックがないこと（何も表示されなければ OK）:

```sh
ffprobe -v error -select_streams a -show_entries stream=index -of csv=p=0 pos2_001.mp4
```

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| カメラの映像が出ない | ブラウザのカメラ許可を確認。`file://` で開いている場合はローカルサーバー経由で開く。エラー内容は画面下部のログに出ます |
| 黄色の「below target」が出る | カメラの解像度が足りず引き伸ばして保存しています。録画はできますが、画質は落ちます |
| 黄色の「TIME-BASED」が出る | PC の Chrome / Edge で開き直してください |
| カメラ切り替え・Position・Start # が操作できない | 録画中・カウントダウン中はロックされます。STOP を押すと解除されます |
